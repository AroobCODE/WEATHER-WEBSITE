# Weather Website

A modern, responsive weather website designed to help users explore current weather conditions and forecasts for locations around the world.

## Features

- 🌍 **Worldwide Weather Search** — Search for cities and locations around the world.
- 🌡️ **Current Weather** — View temperature, weather conditions, and other available weather information.
- 🕒 **Hourly Forecast** — Explore upcoming weather conditions throughout the day.
- 📅 **Daily Forecast** — Check the weather forecast for upcoming days.
- 💨 **Detailed Weather Information** — View available data such as humidity, wind speed, pressure, visibility, and UV index.
- 🌙 **Theme Support** — Switch between light and dark themes.
- ⚙️ **Customizable Settings** — Adjust available preferences, such as temperature units.
- ⭐ **Favorite Locations** — Save locations for quick access.
